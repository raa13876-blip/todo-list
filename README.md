# Мои задачи — To-Do List

Простой и аккуратный список задач. Сайт сделан на чистом HTML, CSS и JavaScript, без фреймворков и сборки.

## Функционал

- **Добавление задач.** Поле ввода и кнопка «Добавить» (или Enter). Задаче можно назначить категорию: Сегодня, Работа или Личное.
- **Отметка выполненных.** Чекбокс зачёркивает задачу и переносит её вниз списка, прогресс дня обновляется сразу.
- **Удаление задач.** Крестик у каждой задачи и кнопка «Очистить выполненные».
- **Сохранение после перезагрузки.** Задачи хранятся в `localStorage` и синхронизируются между открытыми вкладками.
- **Тёмная тема.** Кнопка в правом верхнем углу; выбор запоминается, по умолчанию берётся системная тема.
- **Дополнительно.** Фильтры «Все / Активные / Выполненные» со счётчиками, категории в боковой панели, индикатор прогресса, адаптивная вёрстка для телефона, защита от пустых задач.

## Запуск

Откройте `index.html` в браузере. Устанавливать ничего не нужно.

## Структура

```
index.html   — разметка
style.css    — стили (дизайн-токены из макета Figma)
app.js       — логика: состояние, рендер, localStorage
```

## Использованные инструменты

- **Figma** — собственный дизайн интерфейса.
- **Claude Code** (AI-ассистент от Anthropic) — через Figma MCP получил стили из макета (цвета, шрифты, отступы), сверстал страницу, написал логику и проверил работу в headless-браузере (Playwright): добавление, отметка, удаление, сохранение после перезагрузки, мобильная вёрстка.
